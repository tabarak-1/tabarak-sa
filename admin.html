لوحة إدارة الموقعالعودة إلى الموقع

تسجيل الدخول

عدّل أي شيء في موقعك (الصفحات والخدمات والمقالات والصور والألوان)، وتُنشر التغييرات تلقائياً عبر GitHub.

كيف أحصل على رمز الوصول؟ (مرة واحدة فقط)
  1. سجّل الدخول إلى GitHub ثم افتح: Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens.
  2. اضغط Generate new token وسمّه مثلاً tabarak-admin، واختر مدة الصلاحية (مثلاً سنة).
  3. في Repository access اختر Only select repositories ثم اختر مستودع موقعك فقط.
  4. في Permissions ← Repository permissions اجعل Contents على Read and write.
  5. اضغط Generate token وانسخ الرمز (يبدأ بـ github_pat_) والصقه هنا.

الرمز يعمل على مستودع موقعك فقط، ويُخزَّن في متصفحك ولا يُرسل إلا إلى GitHub. لا تشاركه مع أحد.
