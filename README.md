# موقع شركة تبارك

موقع ثابت (HTML/CSS) سريع ومجاني الاستضافة، مهيأ لمحركات البحث، يدعم العربية (RTL)، ويُدار بالكامل من لوحة `admin.html`.

## النشر المجاني على GitHub Pages
1. ارفع **محتويات** هذا المجلد (وليس المجلد نفسه) إلى مستودعك: Add file ← Upload files.
2. من Settings ← Pages اختر Deploy from a branch ← `main` ← `/(root)` ← Save.
3. بعد دقيقة افتح موقعك (مثل `https://tabarak-1.github.io/tabarak-sa/`).

## لوحة الإدارة: `admin.html`
افتح `https://موقعك/admin.html` وعدّل أي شيء دون لمس الملفات:

| التبويب | ما تعدّله |
|---|---|
| الصفحة الرئيسية | كل نصوص الصفحة، النقاط، "لماذا نحن"، الخطوات، معرض الأعمال، الأسئلة الشائعة |
| الخدمات | إضافة/تعديل/حذف/ترتيب الخدمات (لكل خدمة صفحة كاملة وقائمة أسئلة) |
| صفحات إضافية | صفحات جديدة مثل "من نحن" مع خيار إظهارها في القائمة |
| المقالات | إضافة وتعديل وحذف المقالات مع صورة رئيسية ومساعد سيو |
| إعدادات الموقع | الاسم، الهاتف والواتساب، المدينة، الأحياء، الألوان، رابط الموقع، أكواد التحقق |

**المحرر الغني:** عناوين، غامق/مائل، قوائم، اقتباس، ملاحظة مميزة، **صور** (رفع من الجهاز أو من مكتبة الصور)، جداول، فيديو يوتيوب، زر اتصال وزر واتساب، روابط، وعرض كود HTML. الصور تُضغط تلقائياً قبل الرفع.

**الإعداد (مرة واحدة):** أنشئ رمز وصول (Fine-grained token) من GitHub:
Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token ←
اختر مستودع الموقع فقط ← Repository permissions ← **Contents: Read and write**.
ثم الصق الرمز في صفحة الدخول مع اسم المستودع (مثل `tabarak-1/tabarak-sa`).

**ملاحظات:**
- الرمز يُخزَّن في متصفحك فقط. لا تشاركه، ولا تفعّل "تذكّرني" على جهاز عام.
- كل حفظ يُنشر في commit واحد ويظهر على الموقع خلال دقيقة أو دقيقتين.
- المحتوى محفوظ في `data/content.json` و`data/posts.json`، والصور في `assets/uploads/`.
- الصفحات تُولَّد من هذه الملفات بواسطة `assets/site-core.js` (تلقائياً عند الحفظ). لا تعدّل ملفات HTML يدوياً لأن الحفظ التالي سيعيد توليدها.
- بعد نشر أي مقال أو صفحة جديدة: افتحها في Google Search Console ← فحص الرابط ← طلب الفهرسة.
- إن عدّلت الموقع من جهازك بعد استخدام اللوحة، حمّل آخر نسخة من GitHub أولاً حتى لا تفقد التعديلات.

**غير قابل للتعديل من اللوحة:** تصميم الشعار (الشكل)، وتخطيط الصفحات، والنصوص الثابتة مثل أزرار "اتصل الآن" و"اقرأ المزيد". هذه تتطلب تعديل الكود.

## توليد الصفحات من جهازك (اختياري)
إن عدّلت `data/*.json` يدوياً: `node tools/build.js`.

## السيو
**تم في الموقع:** عناوين وأوصاف لكل صفحة، بيانات منظمة (شركة محلية، خدمات، أسئلة شائعة، مقالات، مسار التنقل)، صورة مشاركة، أيقونات، محتوى محلي، روابط داخلية، sitemap وrobots.

**عليك أنت (الأهم):**
1. **Google Search Console:** أضف الموقع بطريقة "بادئة عنوان URL"، وضع كود التحقق في لوحة الإدارة ← إعدادات الموقع ← "كود التحقق"، ثم أرسل `sitemap.xml`.
2. **Google Business Profile:** أنشئ ملفاً للشركة بنفس الاسم والرقم وحدّد منطقة الخدمة "جدة" وأضف صوراً حقيقية. هذه أقوى خطوة للبحث المحلي.
3. **الأحياء:** عدّل قائمة المناطق في إعدادات الموقع لتطابق مناطق خدمتك الفعلية.
4. **صور أعمالك:** أضفها في "معرض الأعمال" بالرئيسية وفي المقالات مع وصف لكل صورة.
5. **التقييمات:** اطلب من عملائك تقييمك على خرائط جوجل ولا تكتب آراء مختلقة.
6. **مقال كل أسبوع أو أسبوعين** مع التزام مساعد السيو في اللوحة.
